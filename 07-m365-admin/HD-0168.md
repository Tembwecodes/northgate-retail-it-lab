# HD-0168 — Licence assignment unavailable from Entra ID user profile

**Category:** Licensing / admin console navigation
**Department:** Head Office IT
**Priority:** Low

## Symptom
Attempted to assign a Microsoft 365 E3 licence to a newly created user directly from their profile's Licenses page in the Microsoft Entra admin center. The page displayed as read-only with no way to assign a licence.

## Diagnosis
The page carried a banner directing to "Go to M365 Admin Center" to manage licences, confirming licence assignment has been moved out of the Entra ID user experience entirely and now lives solely in the Microsoft 365 admin center's per-product "Assign licenses" flow.

## Resolution
Navigated to the Microsoft 365 admin center, selected the Microsoft 365 E3 product, and used its "Assign licenses" panel to search for and licence the user directly. Repeated this process (and later, the bulk "up to 20 at once" option) for all subsequent users.

## Root cause
Console consolidation on Microsoft's side, not a fault. User creation and licence assignment are now split across two separate admin portals.

## Outcome
All 12 users licensed successfully via the M365 admin center. Noted for future reference: user creation happens in Entra ID, licensing happens in the M365 admin center, and the two don't fully overlap.
