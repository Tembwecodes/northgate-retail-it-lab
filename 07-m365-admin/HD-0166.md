# HD-0166 — M365 Developer Program signup rejected, pivoted to E3 trial

**Category:** Cloud identity / tenant provisioning
**Department:** Head Office IT
**Priority:** Standard

## Symptom
Signed up for the Microsoft 365 Developer Program using a new personal Microsoft account, with correct profile details and verified contact information. The dashboard returned: "You don't currently qualify for a Microsoft 365 Developer Program sandbox subscription," with no further explanation or visible eligibility criteria.

## Diagnosis
Researched the error and found it's a known but undocumented issue, sometimes resolving itself after a cooldown period on newly created Microsoft accounts. Waited two full days to rule this out before treating it as a genuine blocker rather than a timing issue.

## Resolution
After the two-day wait produced no change, abandoned the Developer Program signup route entirely and provisioned a standard Microsoft 365 E3 trial instead, via the normal enterprise trial signup flow rather than the developer sandbox path. This succeeded immediately. Noted the trial's auto-renewal date and cancellation window at signup to avoid an unwanted charge later.

## Root cause
Undetermined on Microsoft's side (account-level eligibility gate with no visible criteria). Not a configuration error on my part.

## Outcome
Tenant "Northgate Retail" provisioned successfully on Microsoft 365 E3, unblocking the rest of Project 7 with a documented scope adjustment (E3 rather than the originally planned E5/Developer tier).
