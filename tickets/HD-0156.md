HD-0156: Application Won't Launch From Desktop Shortcut
Category: Desktop Support Priority: Standard Status: Resolved

Summary
An application failed to launch from its desktop shortcut on Win11-TroubleshootVM. Editing the shortcut's target path in place didn't resolve it, the fix required deleting and recreating the shortcut entirely due to Windows caching the shortcut's original target internally.

Problem
Simulated a broken shortcut fault, clicking the desktop shortcut for an application did nothing, or returned an error that the target couldn't be found.

Discovery
Checked the shortcut's Properties and found the Target path pointed somewhere invalid (the simulated fault). Corrected the Target field directly in Properties and applied the change, expecting that to fix it.

The shortcut still failed to launch the application after the target was corrected, even though Properties now showed the right path.

Fix
Deleted the broken shortcut entirely and created a brand new shortcut pointing at the application's correct executable path.

Verification
Double-clicked the newly created shortcut and confirmed the application launched successfully.

Root Cause
Windows can retain an internally cached reference to a shortcut's original target independent of what's displayed and edited in the Properties dialog, so correcting the visible Target field doesn't always update the actual link data the shortcut launches from. Deleting and recreating the shortcut forces a clean link with no stale reference.

Resolution
* Diagnosed the broken shortcut via its Properties, confirming an invalid Target path
* Attempted to fix the Target path in place, which did not resolve the launch failure
* Deleted the shortcut and created a new one pointing at the correct executable
* Confirmed the application launched successfully from the new shortcut

Lessons Learned
* Editing a shortcut's Target field doesn't always fix a broken shortcut, Windows can hold onto stale internal target data
* When a shortcut fix doesn't take after editing Properties, delete and recreate the shortcut rather than repeatedly re-editing it
