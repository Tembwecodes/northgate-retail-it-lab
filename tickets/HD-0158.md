HD-0158: Machine Running Slow Due to Runaway Process
Category: Desktop Support Priority: Standard Status: Resolved

Summary
Win11-TroubleshootVM became sluggish and unresponsive under normal use. Diagnosed via Task Manager as a single process consuming excessive CPU, resolved by ending the process.

Problem
Simulated a general slow-performance fault, the machine was noticeably laggy across normal tasks, with no specific application or error pointing to the cause.

Discovery
Opened Task Manager and sorted processes by CPU usage, immediately surfacing a single process consuming a disproportionate share of CPU compared to everything else running, well beyond what would be expected for a machine otherwise sitting idle.

Fix
Ended the runaway process via Task Manager.

Verification
Confirmed CPU usage dropped back to a normal baseline immediately after ending the process, and that general responsiveness returned to normal.

Root Cause
A single process was consuming excessive CPU, starving the rest of the system of resources and causing the overall slowdown, rather than a systemic issue affecting multiple processes.

Resolution
* Diagnosed the slowdown via Task Manager, sorted by CPU usage
* Identified a single process consuming a disproportionate share of CPU
* Ended the process and confirmed CPU usage and responsiveness returned to normal

Lessons Learned
* Sorting Task Manager by CPU (or Memory) usage is the fastest way to isolate a resource-hogging process behind a general "slow computer" complaint
* Not every slow-performance ticket needs a deep systemic diagnosis, a single misbehaving process is a common and quick-to-confirm cause
