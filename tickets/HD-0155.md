HD-0155: Websites Won't Load Despite Working Network Connection
Category: Desktop Support Priority: Standard Status: Resolved

Summary
Win11-TroubleshootVM had a working network connection but couldn't reach any websites by name. Diagnosed as a DNS resolution failure rather than a connectivity fault, fixed by resetting DNS settings back to DHCP-assigned values.

Problem
Simulated a fault where the machine could reach the network (ping to an IP address succeeded) but browsing to any website failed, and pinging by hostname also failed, pointing away from a general connectivity issue.

Discovery
Confirmed via ping that an IP address (e.g. a known working IP) was reachable, ruling out a network-layer fault. Pinging a hostname failed to resolve, isolating the problem to DNS specifically.

Checked the adapter's DNS settings and found a manually configured, incorrect DNS server address rather than the expected DHCP-assigned one, this was the injected fault.

Fix
Reset the adapter's DNS settings back to obtain DNS server address automatically, removing the incorrect manual entry.

Verification
Ran ipconfig /flushdns to clear any cached bad lookups, then confirmed hostname resolution worked via ping and by successfully loading a website.

Root Cause
A manually configured DNS server address had been set on the adapter, overriding the correct DHCP-assigned DNS server and breaking name resolution while leaving raw IP connectivity unaffected.

Resolution
* Confirmed IP-level connectivity was fine via ping, isolating the fault to DNS
* Found and removed an incorrect manually configured DNS server address
* Reset the adapter to obtain DNS automatically via DHCP
* Flushed the DNS cache and confirmed hostname resolution and browsing worked

Lessons Learned
* Testing connectivity by IP address first, then by hostname, is a fast way to separate a network fault from a DNS fault
* Manually configured DNS settings are an easy thing to overlook when a machine otherwise looks correctly connected
* Always flush the DNS cache after a DNS fix, a stale cached failure can outlast the underlying problem
