HD-0157: Printer Not Responding, Print Spooler Stopped
Category: Desktop Support Priority: Standard Status: Resolved

Summary
A printer on Win11-TroubleshootVM stopped responding to print jobs, with jobs stuck in the queue and never completing. Traced to the Print Spooler service being stopped, resolved with a restart.

Problem
Simulated a printer fault, print jobs sent to the printer sat in the queue without printing or clearing, and the printer appeared unresponsive from the user's side.

Discovery
Checked the Print Spooler service via services.msc and found it in a Stopped state, rather than Running as expected. This explained why jobs were queuing but never being processed.

Fix
Restarted the Print Spooler service (Start, or a full Stop/Start cycle where a simple Start didn't clear the existing stuck state).

Verification
Confirmed the Print Spooler service showed Running, then sent a fresh test print job and confirmed it completed successfully without needing to be manually cleared.

Root Cause
The Print Spooler service had stopped, a service Windows depends on to manage the print queue, so jobs backed up in the queue with nothing to process them.

Resolution
* Diagnosed the stuck print queue as a stopped Print Spooler service via services.msc
* Restarted the Print Spooler service
* Confirmed a fresh test print completed successfully

Lessons Learned
* A stuck print queue with no error message is a strong first indicator to check the Print Spooler service state before troubleshooting the printer itself
* Restarting a stopped core service is often a faster and more reliable fix than trying to clear a stuck job queue manually
